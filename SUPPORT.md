# Support

Mnemo is maintained as an open source project. Support is offered on a best-effort basis.

## Bugs

Report a reproducible problem through the [bug report form](https://github.com/onemnemo/mnemo/issues/new?template=bug.yml).

Do not attach API keys, private material, complete backups, or other sensitive data to a public issue.

## Questions

Use [GitHub Discussions Q&A](https://github.com/onemnemo/mnemo/discussions/categories/q-a) for installation help and questions about using Mnemo. Public answers can help the next person with the same question.

For a support request that cannot be discussed publicly, email [help@mnemo.one](mailto:help@mnemo.one).

## Ideas and beta feedback

Use [Ideas](https://github.com/onemnemo/mnemo/discussions/categories/ideas) for feature proposals. Use [Discussions](https://github.com/onemnemo/mnemo/discussions) for broader beta feedback and first impressions.

## Security

Do not report a vulnerability in a public issue or discussion. Follow the private reporting instructions in [SECURITY.md](SECURITY.md).

## Other contact

- General project enquiries: [contact@mnemo.one](mailto:contact@mnemo.one)
- Press enquiries: [press@mnemo.one](mailto:press@mnemo.one)
